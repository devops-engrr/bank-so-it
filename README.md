# Bank SO IT Website

Official companion website for the Bank SO IT YouTube channel.

## Sections
- Home
- Videos
- Daily Quiz
- Resources
- Announcements
- About

## Deployment
This is a static website designed for GitHub Pages.

Repository: `bank-so-it`

YouTube: https://www.youtube.com/@BankSoIt

Cheat Sheets: https://drive.google.com/drive/folders/1mglPEsevsobkY-y0oCxEwVBqJweAtWQ6

## Before publishing
1. Replace `YOUR-USERNAME` in the Open Graph URL inside `index.html`.
2. Add your real domain later if you purchase one.
3. Update announcement content as new videos/quizzes are published.
4. Add your logo/favicon when the final brand asset is ready.

## Branding
The website uses the Bank SO IT logo supplied by the channel owner.
